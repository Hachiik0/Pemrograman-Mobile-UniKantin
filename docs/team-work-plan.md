1. Pembagian di atas merupakan **usulan** pembagian tanggung jawab.

3. Setiap anggota diharapkan memberikan review terhadap minimal satu dokumen milik anggota lain.
4. Perubahan atau koreksi setelah review dicatat melalui commit Git dengan pesan yang jelas.
